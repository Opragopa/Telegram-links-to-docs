# Экспорт постов Telegram-канала

Инструмент для SMM-специалистов: собирает посты канала за период, показывает их в таблице со ссылками, временем публикации и метриками охвата, делает PNG-скриншот каждого поста и выгружает всё в Excel или CSV.

## Что попадает в отчёт

Для каждого поста собираются дата и время публикации в вашем часовом поясе, ссылка на сообщение, полный текст и число символов, просмотры, реакции (с разбивкой по эмодзи), пересылки, комментарии, тип медиа, число файлов в альбоме и признак репоста. Альбомы из нескольких файлов считаются одним постом.

## Быстрый запуск на macOS

Скачайте DMG из GitHub Releases, откройте его и перетащите `Telegram Posts Exporter.app` в Applications. Затем запустите приложение двойным кликом. Оно само установит зависимости, запустит локальный веб-интерфейс и откроет его в браузере. При первом запуске macOS может попросить подтвердить открытие приложения.

При первом запуске введите API ID, API Hash, номер телефона, код Telegram и пароль 2FA. API-данные, Telethon-сессия и результаты сохраняются в папке `data/` внутри проекта, поэтому при следующих запусках вход уже не понадобится.

## Как пользоваться

1. Войдите в Telegram в блоке слева. Если сессия уже сохранена, блок свернётся сам.
2. Укажите канал и период — быстрые кнопки «7 дней», «30 дней», «Этот месяц», «Прошлый месяц» заполняют даты в один клик. Обе даты включаются в выборку.
3. Нажмите «Начать экспорт». Прогресс, оставшееся время и текущий пост видно в реальном времени, экспорт можно остановить кнопкой «Остановить» — уже созданные файлы сохранятся.
4. Готовые посты появятся в таблице справа: превью скриншота, время публикации, текст, ссылка и метрики. Строку можно раскрыть кнопкой «Открыть пост», превью — увеличить кликом.
5. Ищите по тексту и ссылкам, сортируйте по дате, просмотрам, реакциям или пересылкам, отмечайте нужные посты галочками.
6. Нажмите «Excel» или «CSV», чтобы выгрузить таблицу. Если отмечены отдельные посты, выгрузятся только они. «Копировать ссылки» кладёт в буфер обмена пары «дата — ссылка» для вставки в контент-план.

Прошлые выгрузки остаются в блоке «История экспортов» — их можно открыть повторно без обращения к Telegram.

В Excel-файле скриншоты постов встроены во вторую колонку — сразу рядом с датой, ссылки кликабельны, первая строка закреплена с автофильтром. Картинки существуют только в `.xlsx`: CSV и Google Таблицы формат встроенных изображений не поддерживают, туда попадут остальные колонки.

Для публичных каналов скриншоты строятся через официальный Telegram Post Widget: в них сохраняются реальное медиа, подписи, реакции, просмотры и оформление поста. Для приватных каналов используется резервный локальный вид, построенный из данных Telethon.

Чтобы полностью завершить работу приложения, нажмите вверху интерфейса кнопку «Закрыть приложение». Она остановит локальный сервер и сохранит уже созданные результаты. Простое закрытие вкладки браузера само по себе сервер не останавливает.

## Запуск из исходников

Для macOS/Linux скачайте репозиторий и выполните:

```bash
chmod +x start.sh start.command
./start.sh
```

Для сборки DMG из исходников выполните `./build_macos_dmg.sh 0.1.0`. Скрипт упаковывает файлы приложения внутрь `.app`, поэтому DMG самодостаточен.

## Ручная установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

Для запуска из командной строки создайте `.env` и укажите в нём `TG_API_ID`, `TG_API_HASH` и канал. API-данные выдаются в [my.telegram.org](https://my.telegram.org).

## Запуск скрипта без веб-интерфейса

```bash
python telegram_posts_export.py \
  --channel @example_channel \
  --from 2026-07-01 \
  --to 2026-07-31
```

При первом запуске Telethon запросит номер телефона, код из Telegram и пароль 2FA. Сессия сохранится локально и повторно вводить код обычно не потребуется.

Обе даты включаются в выборку: для отчёта за весь июль укажите `--from 2026-07-01 --to 2026-07-31`.

Результаты появятся в `exports/<канал>_<начало>_<конец>/`:

- `posts.csv` — таблица для Excel/Google Sheets;
- `posts.json` — те же данные в JSON;
- `screenshots/` — PNG-скриншоты;
- `html/` — промежуточные HTML-файлы резервных скриншотов.

Если Playwright или Chromium не установлены, экспорт не прерывается: посты и метрики соберутся, а скриншоты будут пропущены.

## Веб-интерфейс

```bash
python web_app.py
```

Откройте http://127.0.0.1:5050. Задача выполняется в фоне, результаты сохраняются в `data/exports/`, готовые таблицы — в `data/table_exports/`.
